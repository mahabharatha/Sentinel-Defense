# Security Policy

## Reporting a Vulnerability

Do not disclose vulnerabilities for this private repository in public forums, public issue trackers, or social media.

Report vulnerabilities privately to:

- bharath.mailbox1@gmail.com

Include, when possible:

- affected file or component;
- reproduction steps;
- impact summary;
- whether exploitation requires authentication or local access;
- logs, stack traces, or proof-of-concept material.

## Response Guidance

Until a public disclosure policy is explicitly adopted in writing, treat all security findings in this repository as confidential.

## Scope Reminder

Some behavior in this platform depends on third-party packages, model weights, external APIs, or user-provided wrappers. Please identify whether the issue is in:

- platform code;
- a wrapper/adapter;
- a third-party dependency;
- a model or model-serving layer;
- a report-generation path.
