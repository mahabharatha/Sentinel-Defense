PyRIT Options

Use this panel for structured PyRIT runs without hand-writing JSON. The selected attack is declared explicitly here, and local Ollama `.../api/generate` targets are normalized to `.../api/chat` automatically.
Profiles keep the tested text path separate from the new multimodal path. Multimodal in this build means Vision-Language support only: `text + image -> text`.
Single-turn default: `prompt_sending` with one turn and auto scoring.
Select one or more attacks. The available set adapts when you switch between the text and multimodal profiles.
This is the image path you configure explicitly for the VLM run. If this is blank, PyRIT will resolve the actual seed image from the global `Sample Path` and the report will show that fallback.
Set this when you want scoring to use an explicit success string instead of inferring it from the objective. For multiple required words or tokens, enter a comma- or newline-separated list. Use `contains_literal` when all literals must appear, `contains_any_literal` when any one is enough, and `ordered_literals` when the literals must appear in sequence.
`many_shot_jailbreak` uses the bundled dataset count above. `flip` and `skeleton_key` run with their built-in PyRIT templates. `red_teaming` and `crescendo` are text-profile multi-turn attacks and use the adversarial model or endpoint when provided, otherwise they default to the same local target.
Common local test: set `Source Value` to your Ollama endpoint, `Model ID` to the runtime model, and either fill this objective or use the global `Target Text` field.
