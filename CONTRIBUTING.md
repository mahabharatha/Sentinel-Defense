# Contributing

This is a private-source repository.

## Access Model

Only explicitly authorized collaborators may access, modify, review, or test this codebase.

## Contribution Terms

By contributing code, documentation, wrappers, tests, reports, or other materials to this repository, you agree that:

- your contributions are provided for the benefit of the rights holder of this repository;
- you have the right to submit the contribution;
- you are not introducing code or assets that violate another license, NDA, or employer obligation;
- the rights holder may use, modify, relicense, or commercialize the contribution as permitted by applicable contributor agreements or employment terms.

If you need stronger IP assignment or CLA language, add that before inviting external collaborators.

## Pull Request Expectations

- keep changes focused and reviewable;
- include smoke-test notes for code changes;
- state clearly whether a change affects a real model-backed path or only a demo/scaffold path;
- document any new framework integration boundaries honestly;
- do not commit model weights, secrets, proprietary customer samples, or generated scan outputs unless explicitly approved;
- update licensing or compliance notes when adding new third-party dependencies or model families.
